# ADR 0002 — 以可验证的报价边界代替未经证明的最低价

状态：接受。

## 决策

游戏身份、版本、商店报价、用户所在地区、价格货币以及激活限制是独立维度。只比较币种、版本和购买资格均可比较的报价。所有金额使用整数最小货币单位；解析上游金额使用十进制定点计算。

CheapShark 作为首个价格适配器，页面明确显示其 USD 覆盖范围。国区不支持时返回 unsupported，不将 USD 转成 CNY 来伪装本地售价。版本或激活资格未知时显示观测价格和待核验条件，不能将其标为已确认最低可购价。

抓取时间 fetched_at 与上游更新时间 source_updated_at 分开记录。未提供上游时间时保留 null。请求失败不会生成价格或覆盖为零。

数据查询由用户操作触发。首轮不运行价格全量轮询，也不发送外部通知。保存目标价是独立、可验证的账号功能；通知状态明确为未启用。
