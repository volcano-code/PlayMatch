# ADR 0003 — 明确推荐模式与约束证据

状态：接受。

## 决策

推荐运行必须记录实际使用的 rules 或 llm 模式。没有模型密钥时，规则路径仍可完成可复现的产品体验，界面不得声称调用了大模型。模型调用失败后降级时，运行结果必须携带降级原因。

游戏事实来自目录和来源证据。模型负责解释输入意图和组织说明，不得编造商店、价格、平台支持或已证实的功能。结构化输出经过校验，目录以外的游戏 ID 不得进入推荐结果。

硬条件区分满足、冲突、未知；无法证实的中文支持、合作模式、激活资格不能自动变成满足。预算无法用当前可比较报价验证时必须说明，不能在卡片上暗示已经满足预算。偏好不足、候选不足和上游故障都是用户可见的结果状态。

## 验收方向

测试覆盖已拥有排除、负面偏好、未知硬条件、不支持地区、模型输出校验与上游故障。更大规模检索、向量索引、质量评估与分布式恢复作为后续里程碑，不把规划目标写成已取得指标。
