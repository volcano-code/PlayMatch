## 已实现

任务记录本身是 SQL 队列条目。创建任务与首个事件同事务提交，不再依赖提交之后的内存派发。短事务串行化入队与领取，执行和外部请求在锁外运行。数据库时钟统一租约、总时限；每个尝试持有独立 owner token 和递增次数，每次写事件、检查点和结果都校验所有权。

本地默认 embedded 消费同一队列；Compose 配置为 external，由独立 worker 监督单任务子进程。API 重启不再统一判失败。超时、取消、失去租约时，仍存活的监督进程会终止子进程；确认子进程退出后才允许即时重新排队。

`understand`、`retrieve`、`filter` 三个安全阶段完成后提交应用级快照。版本、完整上下文与校验摘要不匹配时重新执行原任务。价格阶段不作为可续建检查点，恢复后重新查询报价。完成状态、最终结果、done 事件同事务提交。

前端区分停止等待与取消任务；同标签页刷新后可继续查看原任务，使用 GET/SSE 而不是再次 POST。跨账号、过期和格式错误引用被拒绝。补充请求身份检查，旧取消响应和旧流式结果不能覆盖新的推荐。

## 使用与限制

操作和参数见 [durable-runs-v04.md](durable-runs-v04.md)。升级前停止旧版 API/worker，保存数据库卷与备份；旧代码不参与新租约写入校验。不要用生产数据运行专用测试 fixture。

这不是第三方调用 exactly-once：外部模型已经接受但阶段尚未入库的调用仍可能重复，默认最多 3 次尝试、总时限 90 秒不是美元计费上限。未增加支付、购买、邮件等不可逆工具。阶段快照是应用实现，不冒称 LangGraph 原生 checkpointer。

embedded 模式无法强杀阻塞线程。external 监督者存活时能终止子进程；只 SIGKILL 监督者可能留下孤儿进程，直到进程退出或整个容器停止。写入 fencing 仍有效，但没有完成跨主机压力、生产进程回收、全局限流或高可用部署验收。

此轮没有真实 IGDB 凭据采集、国区报价、自动降价通知、付费 LLM 调用或独立推荐质量评测。默认仍是 24 款目录、US/USD 观测报价。上一阶段真实开源向量模型验证仍属于 v0.3，不当成本轮再次执行的结果。
