# PlayMatch

通过主题、偏好和约束发现游戏，并查看有来源、有地区边界的购买报价。

项目正在按阶段实现。目标是可运行、可测试的全栈 Agent 产品：Next.js + FastAPI + LangGraph，包含游戏检索、可解释推荐、价格适配器、账号、收藏和反馈。

## 当前开发边界

- 首轮交付可运行的完整流程，后续阶段逐步扩大目录、完善检索和生产运行能力。
- 无模型密钥时明确使用规则推荐；配置模型后再启用真实模型推理。
- 游戏启动目录明确标为人工整理的数据，不冒充实时上游目录。
- CheapShark 报价为 USD；国区未接通时显示不支持，不进行汇率换算来伪装国区价格。
- 版本与激活条件未验证时，只展示观测报价，不声称全网最低或保证可购买。
- 收藏可保存目标价；此阶段不发送邮件、不声称价格提醒已启用。

接口和数据约定见 [implementation-contract](docs/implementation-contract.md)。开发与验证记录会随实现更新。
